# 🚀 Quick Start — Dashboard Bucaneiro

## Passo 1: Abrir o gerenciador

**No Mac (Terminal):**
```bash
cd "/Users/brunovaz/Documents/Claude/Projects/Meu Head de IA/fluxo-caixa-bucaneiro"
bash start.sh
```

Ou simplesmente clique 2x em `start.sh` (pode pedir permissão)

**Resultado:** Um menu com opções aparece no terminal

## Passo 2: Editar localmente

1. Escolha opção **1** no menu
2. Dashboard abre no navegador
3. Edite os dados (recebíveis, pagamentos, etc)
4. Clique em **💾 Salvar**

Os dados ficam salvos no seu computador automaticamente.

## Passo 3: Exportar para GitHub

1. Escolha opção **2** no menu
2. Siga as instruções que aparecem:
   - Vá no navegador com o dashboard aberto
   - Clique em **🌐 Publicar para Sócios**
   - Um arquivo `bucaneiro-dashboard.html` é baixado
   - Renomeie para `index.html`
   - Mova para a pasta do projeto

3. Volta ao menu, escolha opção **3**
4. Confirma o commit e pronto! ✅

## Menu de Opções

```
1. 📂 Abrir dashboard localmente
   → Edita dados, salva no computador

2. 📤 Exportar versão final para GitHub
   → Prepara arquivo para compartilhar

3. 🔄 Sincronizar com GitHub
   → Faz git push automático

4. 📖 Ver instruções
   → Abre este documento

5. ❌ Sair
   → Fecha o menu
```

## ⚠️ Importante

- **Os dados são salvos localmente** no seu navegador
- Cada computador tem sua própria cópia
- Use "Publicar para Sócios" antes de enviar pro GitHub
- Faça backup de vez em quando (opção 2 cria automático)

## 💡 Dicas

- Backup automático: cada export cria um backup em `backups/`
- Você pode reverter a qualquer momento (pasta `backups/`)
- GitHub recebe apenas a versão final (não sincroniza em tempo real)
